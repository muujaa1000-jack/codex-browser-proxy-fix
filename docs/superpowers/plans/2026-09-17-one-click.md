# One-click repair implementation plan

> Execute with superpowers:executing-plans in the existing dedicated repository branch.

**Goal:** Deliver the approved double-click Windows repair tool locally.

**Architecture:** Keep fingerprint-based patching in ProxyFix.psm1; add dynamic manifest discovery and a workflow module; use a WinForms shell with an asynchronous PowerShell worker.

**Tech stack:** PowerShell 7, .NET Windows Forms, existing Codex Node runtime.

## Constraints

No dependencies, force-closing applications, global settings changes, automatic unknown-file patching or private-data publication. All destructive rollback must preserve later edits. Browser recovery remains a separate acceptance step.
